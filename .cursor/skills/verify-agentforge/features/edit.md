# Edit

Edit is the CapCut-style timeline with an agent panel (`/edit`, rail `mode-edit`). Human and agent share one ops log; every agent change is a card with Keep / Undo / Tweak. Without ffmpeg the studio shows `edit-needs-ffmpeg`. Without a gateway key the agent panel is stub (scripted scenarios) and generation is `edit-needs-key`.

## Sub-features

- `edit-shell` shows `edit-studio`, `edit-timeline`, `edit-preview`, `edit-agent-panel`.
- `edit-import` adds a clip from a file (webdev multipart; packaged `pickMedia`).
- `edit-cut` split / trim / move / delete with undo (`edit-ops-count`).
- `edit-cards` Keep / Undo / Tweak; pending cards cancel on Undo.
- `edit-review-gate` `edit-export` disabled until scrub or `edit-review-ok`.
- `edit-titles` ASS-subset title + `edit-parity-check`.
- `edit-generate` Generate tab (image / video / storyboard), `edit-tray`, `edit-recipes`, `edit-starter`.
- `edit-keep-scenarios` S1–S10 and Fill F1–F5 results tables (owner runs).

## How to get to it (user POV)

- Left rail `mode-edit` on Home, or `http://127.0.0.1:3000/edit` when unlocked.

## Driving it with the Agentforge harness

Preconditions: doctor exits 0 with `edit.ffmpeg.found: true`; fixtures generated by `node scripts/edit-fixtures.mjs`.

- **Shell.** `mode-edit` → `/edit`; `edit-studio`, `edit-timeline`, `edit-preview`, `edit-agent-panel` visible; `edit-new-project` creates "Loop 1".
- **Import.** `edit-import` with `talk-60s.mp4` → clip on `edit-track-v1`; `edit-clip` count 1. Probe shows 60 s.
- **Cut.** Select clip, S at 00:05 → 2 clips; Del second → 1; Ctrl+Z restores. Ops list grows by 3 (`edit-ops-count`).
- **Agent.** Composer "Remove the silences" → `edit-card` with `edit-card-undo` / `edit-card-keep` / `edit-card-tweak`; `edit-emit-lock` appears < 5 s then clears. Card status proposed → kept.
- **No-freeze.** While a `detect_silence` job runs, drag another clip. Drag succeeds; no 409 in the network log.
- **Undo cancels.** Start a `transcribe` (or long ffmpeg) card, press Undo (`edit-card-undo`) while pending. Job `cancelled`, placeholder gone, no orphan in `edit-jobs`.
- **Review gate.** After an agent card, `edit-export` disabled; scrub to end or `edit-review-ok`. `edit-export` enabled; export produces mp4 with burnt captions.
- **Parity.** `edit-parity-check` (dev button) renders `frameAt(t)` and screenshots the stage.
- **Cap.** Settings `settings-edit-turn-cap` = 0.5, ask for 3 generations (stub). Plan card (`edit-plan-card`), no jobs.

## Gotchas

- Stub agent replies are scripted per prompt; a live reply needs the operator's key on Windows only.
- ASR unavailable is a note, not a fail.
- Never POST `/api/v1/edit/...` as a substitute for the UI.
