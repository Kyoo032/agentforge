# Edit

Edit is the CapCut-style timeline with an agent panel (`/edit`, rail `mode-edit`). Human and agent share one ops log; every agent change is a card with Keep / Undo / Tweak. Without ffmpeg the studio shows `edit-needs-ffmpeg`. Without a gateway key the agent panel is stub (scripted scenarios) and generation is `edit-needs-key`.

## Sub-features

- `edit-shell` shows `edit-studio`, `edit-timeline`, `edit-preview`, `edit-agent-panel`, plus the header handles `edit-tier`, `edit-jobs`, `edit-export`, `edit-export-progress`, `edit-export-download` and the footer counter `edit-ops-count`. With **no** project open the list side is `edit-project-list` + `edit-starter` + `edit-starter-description` + `edit-project-name` + `edit-new-project`, `edit-export` is disabled, and `edit-composer`, `edit-composer-send`, `edit-import`, `edit-generate-tab` and `edit-ops-count` have count **0**.
- `edit-transport` `edit-play`, `edit-time`, `edit-playhead`, `edit-zoom`, tracks `edit-track-<id>`; a pending (generating) clip renders as `edit-placeholder`, not `edit-clip` (`apps/web/components/edit-timeline.tsx:198`). The preview layers are `edit-preview-image`, `edit-preview-video`, `edit-title-overlay`, `edit-caption-overlay`.
- `edit-ffmpeg-setup` when ffmpeg is missing: `edit-needs-ffmpeg` carries `ffmpeg-install-command` and `ffmpeg-recheck` (re-probes `GET /api/v1/edit/doctor?recheck=1`, throttled to one forced probe per 2 s — `packages/host/src/edit/doctor.ts:30`). `ffmpeg-setup-steps` only renders in the onboarding `variant="full"`.
- `edit-import` adds a clip from a file (webdev multipart; packaged `pickMedia`).
- `edit-cut` split / trim / move / delete with undo (`edit-ops-count`).
- `edit-cards` Keep / Undo / Tweak; pending cards cancel on Undo. The panel also carries `edit-spend-meter`, the gate card `edit-review-card`, `edit-plan-go`, `edit-card-progress`, `edit-card-cancel`, and the unplaced tray `edit-tray` with `edit-tray-item` (`edit-tray-place` / `edit-tray-discard`).
- `edit-review-gate` `edit-export` disabled until scrub or `edit-review-ok`.
- `edit-titles` ASS-subset title + `edit-parity-check`.
- `edit-generate` Generate tab (image / video), `edit-tray`, per-item `edit-recipe-<id>` (the recipes panel has no wrapping testid), `edit-starter`. The Storyboard sub-tab is a placeholder in this build — `Storyboard lands in Phase 3.` The form is `edit-generate` itself, with the sub-tab buttons `edit-generate-image` / `edit-generate-video` / `edit-generate-storyboard` and the fields `edit-generate-tier`, `edit-estimate`, `edit-generate-model`, `edit-generate-seconds`, `edit-generate-still-clip`, `edit-generate-still`, `edit-generate-prompt`, `edit-generate-submit`.
- `edit-keep-scenarios` S1–S10 and Fill F1–F5 results tables (owner runs).
- `edit-prompt-templates` Generate tab › Video: cited, model-agnostic prompt templates (BytePlus Seedance guides + Higgsfield blog) embedded offline. Category bar `edit-prompt-template-categories` (with `edit-prompt-template-category-all`) and filters `edit-prompt-template-category-<id>`, list `edit-prompt-template-list` with items `edit-prompt-template-<id>`, citation `edit-prompt-template-source`, rules `edit-prompt-guide`. Picking fills the prompt + seconds; the model select is untouched.
- `edit-starter-media` starters with bundled sample media (`promo-16x9`, `talk-16x9`, `reels-9x16`, `square-1x1`): clips land on `v1` / `a1` at create time from `apps/desktop/resources/starters/` (packaged: `resources/starters`). Offline only; a missing file is skipped and logged, never fetched. `edit-starter-description` shows the one-liner under `edit-starter`.

## How to get to it (user POV)

- Left rail `mode-edit` on Default, or `http://127.0.0.1:3000/edit` when unlocked.

## Driving it with the DPSBuddy harness

Preconditions: doctor exits 0 with `edit.ffmpeg.found: true`; fixtures generated by `node scripts/edit-fixtures.mjs` into `apps/web/tests/fixtures/edit/` (the mp4/png are gitignored outputs; `script.txt` and `captions.srt` are committed). Use `talk-60s.mp4` for the agent scenarios — S1's canned ranges are frames 300–1395, so a clip under ~47 s makes the card land **zero** ops and the review gate never closes.

Cleanup after driving on a shared desk: there is **no** delete route for an edit project, so remove the `edit_projects` row (its `edit_ops` / `edit_snapshots` / `edit_cards` / `edit_jobs` / `edit_unplaced` children cascade), every `media` row + file you imported under `data/media/<organizationId>/`, and the project's `data/edit/<projectId>/` ffmpeg scratch dir. ## Gotchas

- Stub agent replies are scripted per prompt; a live reply needs the operator's key on Windows only.
- ASR unavailable is a note, not a fail.
- The recipes panel has **no** wrapping testid. Assert a per-item `edit-recipe-<id>` (e.g. `edit-recipe-podcast-clean-up`); `edit-recipes` does not exist.
- Storyboard is Phase 3 work. The sub-tab **button** is `edit-generate-storyboard` (`apps/web/components/edit-generate-tab.tsx:190`) and it does exist; what it opens is the literal copy `Storyboard lands in Phase 3.` with no `edit-generate-prompt`, no `edit-generate-submit` and no `edit-generate-tier`. F1 and F2 stay not drivable, and `animate_storyboard` lives only in the host agent tools. Neither `edit-storyboard-generate` nor `edit-storyboard-animate-all` exists — do not invent them.
- **The project event stream echoes your own ops back.** `appendOps` emits `ops.appended` for every append including yours (`packages/host/src/edit/ops.ts:277`) and the studio folds every such frame (`apps/web/components/edit-studio.tsx:193-203`) with no dedupe. Import (`:302-303`) and the agent stream (`:474-479`) apply the same ops a **second** time and the resulting `applyOp` throw unmounts `EditStudio`. Keyboard / drag edits survive only because `commitOps` (`:235-259`) assigns a plain value. Any Edit recipe that imports or runs an agent turn must reload before asserting, until this is fixed (`docs/internal/unreleased.md`).
- `edit-ops-count` counts the ops **this browser session** posted (`opsPosted`, `apps/web/components/edit-studio.tsx:848-850`), not `project.seq`. It reads `ops 0` after every reload and after every starter seed.
- The template's `seconds` is a **request, not a result**: `pickTemplate` snaps it to the routed model's allow-list (`apps/web/components/edit-generate-tab.tsx:113-117`). Assert `edit-generate-seconds` against `snapVideoSeconds`, not against the template JSON.
- `edit-prompt-templates` renders on the **Video** sub-tab only (`apps/web/components/edit-generate-tab.tsx:283`); its count is 0 on Image and Storyboard.
- A card can exist with **zero ops**: `applyAgentOps` inserts the card row before `appendOps` (`packages/host/src/edit/backend.ts:116-134`) and never reconciles. Check `opIds.length` (or `review.lastAgentSeq`) before asserting that the gate closed.
- `edit-card-undo` does **not** reopen the export gate: `undoCard` appends inverses as `actor: "owner"` (`packages/host/src/edit/undo.ts:65-69`), and only `agent:` ops move `lastAgentSeq`.
- `edit-card-keep` writes **no ops** — it strips the badge, re-snapshots and flips a status (`packages/host/src/edit/undo.ts:83-100`). Touching an agent clip by hand keeps its card automatically (`apps/web/lib/edit-client.ts:250-252`).
- There is no way back to the project list once a project is open — `edit-project-list` only renders in the `!project` branch (`apps/web/components/edit-studio.tsx:687-741`). Reload between projects.
- `createTurnBudget` is per request (`packages/host/src/edit/agent-run.ts:27`), so `settings-edit-turn-cap` never accumulates across turns.
- Never POST `/api/v1/edit/...` as a substitute for the UI.
