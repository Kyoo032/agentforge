# Finance

Finance is a job: brief plus optional pasted figures → section preview → DOCX download. It is not a spreadsheet. Live generate needs a gateway key. Starters load a canned draft without one. The host never invents figures.

## Sub-features

- `finance-rail` reaches `/finance` from `mode-finance` on Default (and any workspace that includes Finance).
- `finance-shell` shows `finance-studio` with empty copy and starter cards (`finance-starters`).
- `finance-starter` loads a preview without a live generate.
- `finance-studio-model` is the generate-bar chat-catalog dropdown.
- `finance-figures-input` holds pasted numbers; `finance-parse` POSTs `/api/v1/finance/parse` for rows the owner confirms. Generate POSTs `/api/v1/finance/stream`.
- `finance-auto-parsed` covers Generate pressed with no rows and no dataset but figures in the brief: the brief itself goes to `/api/v1/finance/parse`, the rows land in the editor, and the click stops there — the owner generates again before anything is computed.
- `finance-download-docx` (studio header) builds a DOCX from the in-memory draft. `finance-download` is the shared artifact bar's Markdown button.
- Stub/no-key generate shows `finance-error` with a Settings hint (HTTP 503).

## How to get to it (user POV)

- Choose Finance on the left rail (`mode-finance`). Default already has the tab.
- Open `http://127.0.0.1:3000/finance` when the tab is unlocked.
- Legal / Marketing / Students presets do not add this tab unless the owner checks it.

## Driving it with the DPSBuddy harness

Preconditions:

- Doctor exits 0.
- `mode-finance` is visible on Default. If count is 0, you are on a desk that hid Finance — switch to Default or add the tab in Workspaces.
- Stub proof stops at starters + generate 503. Live generate only if the operator asked and doctor reports `runtime: "ai"` and `hasOpenai: true`.

- **Open Finance.** Click `mode-finance`. URL matches `/finance`. `finance-studio`, `finance-studio-empty`, and `finance-starters` are visible.
- **Starter.** Click the first `finance-starter`. Preview and `finance-download-docx` are visible.
- **Download.** Click `finance-download-docx` to get a DOCX from the starter (no live model).
- **Generate without a key.** Fill `finance-prompt` and click `finance-generate`. `finance-error` mentions gateway / Settings / API key.
- **Generate with figures only in the brief.** With no rows and no dataset, put the numbers in `finance-prompt` ("Q3 2026 review: revenue IDR 18.4B, COGS IDR 7.9B, opex IDR 6.1B") and click `finance-generate`. Live: `finance-auto-parsed` shows the count and the rows appear in the line-item editor, and no brief is generated by that click. Without a key the same click shows the parse failure in `finance-error`, not the add-items message.
- **Cloud live.** Only after doctor `ai`: one generate. Do not screenshot the key.

## Gotchas

- Default desk unlocks Finance. Seeded Legal / Marketing / Students desks do not.
- Generate is the finance pipeline on `/api/v1/finance/stream`; parse is `/api/v1/finance/parse`. Do not invent a second DOCX path.
- Do not POST `/api/v1/finance/stream` as a substitute for the prompt bar on a live proof.
- A brief with no digit and no currency token still gets the add-line-items `finance-error`. Auto-parse never generates in the same click.
- The DOCX button is `finance-download-docx`; `finance-download` is the Markdown button in the shared artifact bar. They used to share one testid, so a strict `getByTestId("finance-download")` threw on a successful run. Match on the exact id you mean.
- Parse keeps money and rates only. Counts are dropped: a currency-free small whole number whose label names a countable thing (outlets, stores, branches, employees, staff, headcount, units, months, weeks, days, customers, users) never becomes a line item, so "12 outlets" in a brief is not a figure. A row with a currency survives, so "units sold 12000 IDR" still parses.
- Magnitude suffixes are expanded before the model sees them, so parse is checked on the integer, not the shorthand. `/finance/parse` rewrites "IDR 18.4B" to "IDR 18400000000" (and, on locale `id`, "Rp 18,4 M" the same way — `M` is a million in English and `miliar` in Indonesian, decided by the run locale) and `looksScaled` re-scales any row that still comes back as the bare mantissa. Reason: with the `reasoning_effort: "low"` job knob, `deepseek-v4-flash` returned `revenue: 18.4` in 6 of 8 runs on the brief "revenue IDR 18.4B, COGS IDR 7.9B, opex IDR 6.1B, net profit IDR 2.6B" (`gpt-5.6-luna` 2/2 correct). Margins hide it because they are scale-invariant, so on a live parse check a stored amount, not a ratio: the rows in the editor must read 18 400 000 000, not 18.4.
- A live brief on the default job model goes quiet for a long time and that is the model thinking, not a stall. The desk default is `deepseek-v4-flash` (the `hy3` first choice is not on the gateway), and DeepSeek V4 thinks before it answers; its reasoning arrives as `reasoning_content`, which AI SDK 4 drops, so the host sees no stream events at all while the model works. That used to fail the generate at 60 s with HTTP 500 "No stream events from deepseek-v4-flash for 60s" while a short parse on the same model passed. DeepSeek V4, GLM-5.3, Kimi K3 and Qwen3.8-Max now get the reasoning budgets (240 s to the first token, 180 s idle after it), so a one-to-two minute silence in the drafting phase is expected; only a longer one is a fail. Documents and Market resolve to the same default (Market already carried its own 180 s / 150 s override for this).
