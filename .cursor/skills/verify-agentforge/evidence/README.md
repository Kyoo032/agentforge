# Evidence

Proof artifacts for `verify-agentforge` live here as `evidence/<feature>/<run-id>/`.

Keep:

- `doctor.json` — stdout of `scripts/doctor.mjs`
- `action.md` — feature ID, entry point, testids clicked, values typed
- A screenshot and/or accessibility snapshot of the resulting state

Cleanup must not delete this tree. Screenshots and run folders are gitignored; this README is not.
