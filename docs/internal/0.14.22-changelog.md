## Phase B — Research dossier pipeline — 2026-09-07

- **What:** Research is now plan → search → read → extract → synthesize, producing a cited Markdown dossier. Question → 3–5 sub-queries (the question itself always leads) → `web_search` per query (5 hits) → round-robin dedupe by URL, HTTPS only, cap 10 pages → each page read with `web_fetch` (8k chars, 1.5 MB, 10 s, redirects re-validated, injection-guarded) and mined for up to 5 **verbatim** passages (non-verbatim ones are dropped in code) plus a trust note → one synthesis call returns findings citing `[S#]`, contradictions, open questions, and a summary. Unreachable pages stay in the dossier as snippet-only sources with the failure reason. Cancel stops between phases and nothing is saved.
- **Core:** `security/safe-fetch.ts` (moved from host; `fetchPublicHttps` gains a caller `signal`), `content/html-text.ts` (readability-lite: drops script/style/nav/header/footer/aside/form, prefers `<main>`/`<article>`, decodes entities, caps at a sentence boundary with a `[truncated]` marker), `tools/platform/web-fetch.ts` (`web_fetch` platform tool + `fetchPageText`; registered alongside `web_search`; text-like content types only). All exported from `@agentforge/core`.
- **Host:** `research-dossier.ts` (pure pipeline over injected `ask` / `search` / `readPage` deps: `parsePlan`, `dedupeCandidates`, `parseExtraction`, `parseSynthesis`, `notesFromDossier`, `runResearchDossier`; `RESEARCH_CAPS` = 5 queries × 5 hits, 10 pages, 8k chars/page, 3 concurrent reads, 5 passages/source). `research-generate.ts` wires it to the gateway model, `webSearchTool`, and `fetchPageText`, persists `artifacts {mode: research, kind: dossier}` with `meta {question, queries, sourceCount, model, models}`, and returns `{...notes, artifactId, dossierId, dossier: {title, markdown}}` on both `POST /api/v1/research` and `/research/stream`. Knowledge Base `addUrlSource` now uses the same HTML extractor (whole page, title as the source name). `safe-fetch.ts` in host is a re-export.
- **Web:** `research-studio.tsx` shows **Notes** / **Dossier** tabs (dossier rendered with Markdown tables), the progress list now reads planning → searching n/m → reading n/m → drafting → saving with per-source found / read / unreachable lines, and the action row (Download, Send to Knowledge Base as `Dossier`, Make a document, Make a presentation) uses the dossier Markdown. Reopened saved research opens on the Dossier tab.
- **Testids:** `research-tabs`, `research-tab-notes`, `research-tab-dossier`, `research-dossier-preview` (replaces `research-saved-preview`).
- **Tests:** core `security/safe-fetch.test.ts` (6, moved from host, +1 cancel), `content/html-text.test.ts` (4), `tools/platform/web-fetch.test.ts` (4: html read, blocked hosts never fetched, http/binary/empty failures, caps); host `research-dossier.test.ts` (9: plan fallback + caps, round-robin dedupe, verbatim passage filter, citation resolution, end-to-end with fakes asserting skeleton + unreachable source + phase order + extract call count, query/page caps, planner failure still searches, cancel between phases). ## Phase C review fixes (code + security review) — 2026-09-07

- **Model-written SQL runs in a worker that can be killed.** `sql-worker-source.ts` (worker code kept as a string so it loads the same under tsx and inside the packaged `host.cjs`; receives the resolved `better-sqlite3` path, the DDL, and the rows) and `sql-runner.ts` (`createQueryRunner`: one lazily spawned worker per dataset, queries serialized, a query past the 2 s cap terminates the worker and the next query respawns it; `acquire()` / `inUse()` refcount). `run_sql` and the evidence re-run both go through the runner, so a runaway aggregate, recursive CTE, or cartesian join can no longer block the host process. Tests: runaway self-join is stopped in ~100 ms and the runner keeps serving.
- **Guard and caps.** `assertReadOnlySql` now also rejects `pragma_*` table-valued functions, `sqlite_master` / `sqlite_schema` / temp variants, `randomblob` / `zeroblob` / `fsdir`, `WITH RECURSIVE`, and self-joins of `data` without an `ON` / `WHERE` / `USING` predicate (9 new guard cases). Every dataset connection gets `PRAGMA hard_heap_limit` (128 MB) so blob bombs fail with an error. Ingest caps at 200,000 rows (413 above) on top of the 25 MB byte cap; workbooks are read with `sheetRows` so a zip bomb cannot expand past the cap. The HTTP adapter refuses request bodies over 26 MB before buffering them (413 `payload_too_large`).
- **Dataset text passes the injection guard.** `datasetBrief` scans headers, top values, and the 20 sample rows with the same guard as pasted source material; on a hit the numeric profile stays and the text parts are withheld (a `job.step` says so, the model is told to query instead). Owner bypass in Settings applies as for chat.
- **Charts never zero-fill.** Rows where a plotted series is missing or non-numeric are left out of the chart instead of being drawn as 0.
- **Store fixes.** Cache keyed by workspace + id (another desk's lookup can no longer evict a live dataset); delete returns 409 while a job holds the dataset; a failed DB insert removes the file it just wrote; unreachable multipart `name` branch removed; `irr` returns null when the discount factor underflows instead of a stray number; the Data prompt clears after a successful ask.
- **Dependency:** `xlsx` upgraded from the last npm release (0.18.5, CVE-2023-30533 / CVE-2024-22363) to SheetJS 0.20.3 from `cdn.sheetjs.com` (pinned tarball URL in `packages/core/package.json`); all 127 tabular tests pass unchanged.
- **Known residuals (documented, not fixed):** `tableToCsv` does not neutralize leading `=`/`+`/`-`/`@` (formula injection on re-open in Excel) — it is not wired to any download yet; the number guard treats unitless integers ≤ 12 and years as free text, so "grew by 8" passes unverified.

### Mac pack checklist (on a Mac)

1. `pnpm install`, drop `ffmpeg` + `ffprobe` for the arch into `apps/desktop/resources/ffmpeg/`, `chmod +x`.
2. `pnpm desktop:build:mac:dir` then `pnpm desktop:mac`; drive the 7-step smoke list in `platform/macos/AGENTS.md`; `doctor --desktop`.
3. `pnpm desktop:build:mac` → four artifacts in `apps/desktop/dist/`; install the dmg on a clean user account and repeat steps 1, 3, 4, 7 of the smoke list.
4. Copy the four mac files into `apps/desktop/dist/` on the Windows box next to the Setup exe, then `pnpm desktop:release --dry-run --require-mac` and `pnpm desktop:release --require-mac`; never a `latest-mac.yml`.
