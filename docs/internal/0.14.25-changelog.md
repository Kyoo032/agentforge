## Phase E — Market Watch (prompt-driven analyst, any tickers, chart per ticker) — 2026-09-09

**What:** A new job mode, Market. The user pastes a watchlist (up to 15 tickers from any market: `MU, NVDA, SPCX, BBCA, ^VIX …`), keeps or edits a briefing instruction (default: the pre-market favorites briefing in Bahasa Indonesia with TL;DR + confidence, macro, watchlist snapshot, bullish-to-bearish ranking, catalysts, position focus, signals at the open, risk note, under 6,000 characters), optionally pastes position context ("MU: $100 @ $860, $200 @ $900, target $1,000"), and generates. The host resolves symbols, fetches quotes with pre/post-market moves, two years of daily bars, TradingView technical ratings, headlines, and macro levels (S&P/Nasdaq/Dow/Russell futures, VIX, 10Y, WTI, DXY, IHSG, USD/IDR), builds a line chart per ticker (close, SMA50, SMA200), computes the U.S. session from the run clock so a late run never poses as pre-market, and hands the packet plus the instruction to the model, which may call `market_news`, `market_quotes`, `market_history`, `calculator`, and `web_search`/`web_fetch` when a search key exists. Every figure in the prose is checked against the packet, headline figures, and the user's position context; imperative directives are removed; the disclaimer is stamped by code. On demand only; no schedule yet. No server, no sidecar, no port, no Settings fields. First version (LQ45-only, rule-based bull/bear) was rejected by Kyo the same day and replaced; decision record in `market-mode-plan.md`. Built on branch `feat/market-mode` in the `agentforge-market` worktree from `main` 4f1ce13; not merged.

**DB:** `market_cache(id, ticker, kind, payload, source_ref, observed_at)` + index, kinds `quote|technical|history|news|macro`, and FTS5 `market_news_fts`. `drizzle/0008_market.sql`, journal idx 8, `ensure-schema.ts` mirror.

**Core:** `packages/core/src/market/` — `watch-schemas.ts` (ResolvedSymbol / Quote / Technical / TradingViewRating / WatchNewsItem / PriceHistory / TickerPacket / MacroSnapshot / MarketClock / MarketWatchPacket / MarketWatchRequest, http(s)-only URLs, caps), `advice-guard.ts` (imperative-only pattern: `beli sekarang`, `jual sekarang`, `buy now`, `sell now`, `you should buy/sell` …; ranking, targets, levels allowed), `technicals.ts` + `indicators.ts` (RSI14, SMA50/200, EMA200, MACD, 1d/5d/1m changes, 52-week range), `symbols.ts` (input normalisation, `BBCA` → `BBCA.JK` via the LQ45 alias file, Yahoo exchange → TradingView exchange map, TradingView label thresholds), `market-clock.ts` (US session in America/New_York), `chart-builder.ts` (DataChart line per ticker), `briefing-prompt.ts` + `prompt-format.ts` (default ID/EN prompts, system prompt, rounded packet block, allowed-number set incl. headline figures), `staleness.ts` TTLs, `disclaimer.ts`. `artifacts/market-briefing.ts` (zod + Markdown with watchlist/macro/chart/headline tables; kind `briefing`). `finance/number-guard.ts`: a lone `X.YYY` token now carries both the decimal and the grouped reading (was read as thousands only). `runtime/stream-watchdog.ts` + `types.ts` + `ai-sdk-runtime.ts`: per-run `streamWatchdog` override (raise only). `runtime/invoke-guarded.ts`: the five market tools in `NETWORK_SOURCED_TOOLS`.
