## In-app updates: public releases repo + hardening — 2026-09-07

- **Root cause found:** `Kyoo032/agentforge` is private; electron-updater's GitHub provider fetches `releases.atom` / `latest.yml` unauthenticated, GitHub answers 404, and the raw `HttpError` (URL + full headers JSON) was rendered verbatim on Settings `app-updates-status`. Reproduced with the real provider against the live repo; the shipped v0.14.0 release itself is correct (exe + blockmap + latest.yml).
- **Decision (operator):** release assets move to a separate **public** repo, `Kyoo032/DPS-Agent-Platform` ("DPS Agent Platform", created 2026-09-07). Source stays private. No token is ever embedded in the installer.
- **Config:** `branding/agentforge/brand.json` `updates.repo` and `apps/desktop/package.json` `build.publish.repo` both `DPS-Agent-Platform`; `pack-brand.mjs` now reads `brand.updates` (validated) instead of hardcoding owner/repo. `extraMetadata.version` removed: `version` in package.json is the single source for `app.getVersion()`, the artifact name, and `latest.yml` (verified in app-builder-lib 25.1.8 `packager.js` / `appInfo.js` / `fileTransformer.js`).
- **pack-brand.mjs:** deleted the `latest.yml` rewrite (0.14 phase-5). It was wrong (electron-builder's hyphenated `Agentforge-Setup-X.exe` is the correct GitHub name, and the provider re-hyphenates anyway) and broken (regex had a literal `\.` so `url` never matched; only `path` was rewritten, leaving `dist/latest.yml` mixed). Correction line appended to `0.14-changelog.md`.
- **Desktop main (`auto-update.cjs`):** `describeUpdateError()` maps 404 / other HTTP / ENOTFOUND-ECONNREFUSED-ECONNRESET-ETIMEDOUT-EAI_AGAIN / `ERR_UPDATER_*` / checksum errors to one short line (≤160 chars); `updates:check` and `updates:download` return `{status:"error", message}` instead of rejecting; file logger at `<logs>/updater.log` (one line per entry, raw error detail kept there, never throws); `autoInstallOnAppQuit=false` (this app exits via `app.exit()`, so Electron's `quit` never fires); `updates:install` only acts when `status==="ready"` and calls `onInstallStart` first.
- **Desktop main (`main.cjs`):** `installingUpdate` flag set by `onInstallStart`; `exitApp()` skips the `taskkill /F /T` tree walk in that case so the detached NSIS installer that `quitAndInstall` just spawned is not killed with the app (`installer.nsh` `customInit` already reaps leftovers).
- **Web (`app-updates.tsx`, new `lib/app-updates-copy.ts`):** status/version copy moved to pure helpers; `shortUpdateMessage()` collapses updater dumps to `404 Not Found` and caps length; `supported` now comes from the main-process snapshot (`state.supported`), not the static preload flag, so dev / failed-load builds no longer show an enabled no-op button; `break-words` on the status line; download returning an error state no longer proceeds to install.
- **Release script:** new `apps/desktop/scripts/release-desktop.mjs` (`pnpm desktop:release`): asserts package/brand/publish agree, tree clean (`--allow-dirty`), one Setup exe in dist (`--allow-stale`, `--dist <dir>`), latest.yml version/size/sha512/url/path match the exe, then `gh release create v<version> --repo <owner>/<repo>` uploading exe + blockmap + latest.yml under hyphenated names (`--dry-run`, `--draft`, `--notes <file>`; defaults notes to `docs/internal/<version>-changelog.md` when present). Dry-run verified against `dist-014b` (matches the shipped feed byte-for-byte) and correctly rejects the mixed `dist/latest.yml`.
- **Tests:** new `apps/desktop/auto-update.test.cjs` (plain node:assert, fake app/ipcMain/BrowserWindow/autoUpdater; error mapping, state machine, logger, install guard, 404 → no `Headers`/`{` in UI text); desktop `test` script added so `turbo test` runs it; new `apps/web/lib/app-updates-copy.test.ts` (23). Web vitest 101/101, desktop 2/2, biome clean on touched files (main.cjs keeps 3 pre-existing warnings).
- **Docs:** `apps/desktop/README.md` In-app updates rewritten (public repo, two config places, cut-a-release commands, hyphenated names); verify map `features/desktop.md` `desktop-updates`: an unreachable feed / missing latest.yml is an **error state** with a short message, not "no update".
- **Still to do before 0.14.1 ships:** public `Kyoo032/DPS-Agent-Platform` repo created; `git clean` / empty `apps/desktop/dist/` (19 stale Setup exes); bump `version` → `0.14.1`; `pnpm desktop:build`; `pnpm desktop:release --dry-run` then real; install 0.14.0 → click **Check for updates** → **Update and restart** → prove 0.14.1 launches (this end-to-end has never been driven; record under `evidence/desktop/`).
