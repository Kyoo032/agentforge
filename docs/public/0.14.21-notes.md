# Agentforge 0.14.21

## Fixed

- **Pasting your API key on first run.** Ctrl+V and right-click → Paste now work in the onboarding key field and everywhere else in the app.

## Settings

- **Endpoint URL** is editable. Point Agentforge at your own OpenAI-compatible gateway or a local model server on 127.0.0.1, and use the one-click link to return to Toko Token. HTTPS is required for anything that is not local.

## Updates

- The update control moved from Settings to the bottom of the left rail, next to the dark-mode toggle. A dot on the icon means a new version is ready; click it to check, download, and restart.
