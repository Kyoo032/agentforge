# Agentforge 0.14.0

Highlights since 0.12, rolled up across 0.13.3, 0.13.5, and 0.14.0.

## New desks and modes

- **Enhance** — rewrite a draft in place from Chat and Documents.
- **Finance** — figures-only brief exported to DOCX; it never invents numbers.
- **Data** — paste CSV, get table notes and Markdown; fully offline, no web search.
- **Knowledge Base** — Soul, Memory, Sources, and Map, with dedicated embedding, brain, and verifier models.
- **RAG in Chat** — replies draw on your soul, pinned memories, and vector retrieval (full-text fallback).
- **Chat context chip** — see the Conversation / Attachments / Knowledge / Free breakdown at a glance.

## Chat

- **Enter sends** (Shift+Enter for a newline), in the installed app too.
- **Reasoning effort** — None / Low / Medium / High / Ultra per conversation.
- **Cancel that works** — clear a stuck "Running" and abort in-flight streams.
- **Probe labels** — "1st try… / 2nd try… / 3rd try…" while contacting the model.
- **Stream watchdogs** — hung streams fail closed instead of spinning forever.
- Curated model picker (recommended groups, thinking badge) and richer markdown in replies.
- Switching between Chat and Documents keeps drafts and runs mounted.

## Usage and updates

- **Full Usage page** — day/week/month stacked spend, this-key wallet, per-model breakdown; compact strip in Settings and a usage chip in the Chat header.
- **In-app updates** — the installed app checks this repository from Settings and can update and restart itself.

## Reliability

- Gateway requests are sanitized and fail closed: an invalid parameter returns an error instead of hanging.
- Zero-retention handling on the wire for models that support it.
- Tightened retry and failure paths across the live desks.

## Look

- Industry rail chrome: Barlow type, steel accent, blueprint corners, tighter panel radii.
