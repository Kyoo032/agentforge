# Agentforge 0.14.1

## Edit

- **Starter media** — the Promo, Talk, Reel, and Square starters now open with sample clips and a music bed already on the timeline, fully offline. Swap any clip for your own footage.
- **Prompt templates** — 19 cited video-prompt templates in four categories (promo, talking-head, reel, square) with source links and prompting tips. Picking one fills the prompt and duration; templates work with any model.
- Generate button stays on screen in small windows.

## Updates

- The app now checks this repository for new versions: **Settings → Check for updates**, then **Update and restart** installs in place.
- Update problems show a short, readable message instead of a raw error dump, and details are kept in a local log.
- An update can no longer offer an older version than the one installed.

## Fixes

- Installing an update no longer races the app shutdown.
- Update check and download failures recover cleanly; the panel stays usable.
