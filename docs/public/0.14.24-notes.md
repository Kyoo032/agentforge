# DPSBuddy 0.14.24

## Agentforge is now DPSBuddy

- **New name, new icon.** The app, installer, Start menu entry and window title are now **DPSBuddy**, with the DPS chevron mark. Everything else works the same.
- **Your data comes along.** Installing over Agentforge 0.14.23 upgrades it in place. On first launch DPSBuddy picks up your threads, settings, Knowledge Base and saved gateway key from the Agentforge install; nothing has to be re-entered.
- **Updates keep working.** Releases now live at `github.com/Kyoo032/DPSBuddy`. An installed 0.14.23 still finds this release from **Check for updates**; from 0.14.24 on, the app reads the new address directly.
- **Files to download:** `DPSBuddy-Setup-0.14.24.exe` for Windows, `DPSBuddy-0.14.24-mac-arm64.dmg` / `DPSBuddy-0.14.24-mac-x64.dmg` for macOS (preview, manual update as before).

## Also in this release

- Job studios scroll properly on small windows, and the rail footer is tidier with a clearer theme toggle in dark mode.
- macOS shell rows read the same as on Windows.
- Everything from 0.14.23 (Legal preview, Knowledge Base work cards, offline hardening, bundled video examples) is included.
